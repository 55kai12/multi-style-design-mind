# S6 · Soft Neumorphism（柔和拟物）

关键词：同色系、凸起凹陷、低对比、柔和双阴影、实体感。
公理：光从左上；材质即实体；按压即形变；柔和即舒适。
决策顺序：单一底色 → 光源设定（左上，全局唯一） → 凸/凹双阴影 → 按压形变。

## 色彩系统
- 单一底色：#E0E5EC / #E8EDF2 / #DFE6EE。
- 元素同色系深浅变化：亮 #FFFFFF、暗 #A3B1C6。
- 文字：#4A5568 主，#718096 次。
- 强调：柔和蓝 #5B8DEF 或柔和绿 #48BB78。
- 深色模式：#2D3748 底，#1A202C 暗，#4A5568 亮。
- 禁止：高对比、纯黑、霓虹。

## 字体系统
- 字体族：Nunito / SF Pro Rounded / Quicksand。
- 字号：标题 24/32/40pt，正文 16/18pt。
- 字重：600–700 标题，400 正文。
- 圆润、友好。

## 形状与布局
- 圆角：12–24。
- 间距：16/24/32/48。
- 元素与背景同色。
- 布局宽松，留白充足。

## 材质
- 无毛玻璃。
- 双向阴影：亮阴影 -6/-6 blur 12 rgba(255,255,255,0.8)，暗阴影 6/6 blur 12 rgba(163,177,198,0.6)。
- 内阴影用于凹陷。

## 阴影
- 柔和、同色系，禁止纯黑硬阴影。
- 凸起：双向外阴影。
- 凹陷：双向内阴影。

## 组件规范
- 按钮：凸起 + 按压内凹。
- 卡片：凸起 + 圆角。
- 输入框：凹陷 + 内阴影。
- 导航：凸起条。
- 弹窗：凸起 + 柔和阴影。

## 动效
- 按压内凹、回弹、柔和过渡。150–300ms。
- 禁止：生硬位移、闪烁。

## 特效
- 内阴影、轻微高光。

## 实现要点

### Web / CSS
- 凸起：`box-shadow: -6px -6px 12px rgba(255,255,255,0.8), 6px 6px 12px rgba(163,177,198,0.6);`
- 凹陷：同值加 `inset`。按压 `:active` 从外阴影切到内阴影，`transition: box-shadow 0.2s ease;`
- 字体：Nunito / Quicksand（Google Fonts 免费商用）。
- 阴影颜色必须从底色推导（底色 #E0E5EC → 暗阴影取 #A3B1C6 系），换底色必须重算全套阴影。

### SwiftUI
- 双 shadow 叠加：`.shadow(color: .white.opacity(0.8), radius: 6, x: -6, y: -6)` + `.shadow(color: Color(red: 0.64, green: 0.69, blue: 0.78).opacity(0.6), radius: 6, x: 6, y: 6)`（注意修饰符顺序影响合成）。
- 按压内凹：`@State` 切换凸/凹参数，`.animation(.easeOut(duration: 0.2))`。

### Compose 映射
| 概念 | 等价物 | 注意 |
|---|---|---|
| 双向外阴影 | drawBehind 两次绘制 offset+blur 圆角矩形（亮 -6dp / 暗 +6dp） | Compose 无双向 box-shadow，这是本风格在 Compose 上成本最高的点 |
| 凹陷内阴影 | 同法反向绘制 + clip | 或降级为颜色变化 |
| 按压形变 | interactionSource + animateFloatAsState 切换阴影方向 | tween(200, FastOutSlowInEasing) |
| 圆润字体 | 打包 Nunito 或 FontFamily.SansSerif | — |

诚实告知：Neumorphism 在 Compose 上实现成本显著高于其他风格，预算紧就用「凸起=浅描边+微阴影」简化。

## 可访问性（本风格最高风险，必须主动提示）
- 同色系低对比是风格本体，也是硬伤：主文字 #4A5568 on #E0E5EC ≈ 7:1 达标；次要 #718096 ≈ 4.2:1 勉强达标，禁再淡。
- 所有只靠阴影表达的状态（按下/选中/禁用）对低视力用户不可见——必须附加颜色/图标/文字冗余。
- **必须提供「高对比模式」降级**：描边 + 实色填充替代阴影语义。
- Reduce Motion：按压内凹改为颜色变化。

## 禁用
高对比、纯黑描边、霓虹、玻璃、硬阴影。

## 自检清单
- [ ] 光源是否统一左上（全部元素阴影方向一致）？
- [ ] 是否同色系（出现纯黑描边/霓虹 = S4/S5 残留）？
- [ ] 是否已明示对比度风险并提供高对比降级？
- [ ] 状态表达是否不只靠阴影？
- [ ] 换底色时阴影色是否重算？

## 适用
智能家居、健康、冥想类产品概念、柔和风格 App。
