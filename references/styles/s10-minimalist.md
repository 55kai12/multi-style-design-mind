# S10 · 极简设计风（Minimalist）

关键词：最少元素、最清晰信息、留白、基础型、秩序、功能可见性。
公理：内容为王；留白即呼吸；克制即高级；少即是多。
决策顺序：信息架构 → 单一焦点 → 层级（大小对比 + 留白） → 微动效。特效层为零。

## 色彩系统
- 色调单纯，主色 ≤30% 且唯一。
- 黑白灰建层次：#FFFFFF / #FAFAFA / #F0F0F0 / #D0D0D0 / #999999 / #333333 / #000000。
- 主色示例：蓝 #0055FF、红 #E30613、绿 #00A86B。
- 无渐变、无多主色。
- 每屏只有一个视觉焦点。
- 深色模式：反相。

## 字体系统
- 字体族：无衬线 / 黑体（Inter / SF Pro / Helvetica Neue / 思源黑体）。
- 字号：标题 24/32/40pt，正文 16/18pt。
- 字重：标题 600–700，正文 400。
- 左对齐，稳定阅读路径。
- 行高 1.5–1.6。
- 禁止：花哨字体、多字体混排。

## 形状与布局
- 基础型为主，大而整。
- 圆角：8–16。
- 间距：8/16/24/32/48/64。
- 元素精简，相似不重复。
- 留白充足，明亮背景。
- 网格：12 列，gutter 24。

## 材质
- 无毛玻璃、无渐变。
- 明亮背景 + 充足留白。
- 视觉层次靠留白、大小对比和少量阴影建立。
- 禁止：玻璃、纹理、装饰。

## 阴影
- 微妙：y 2 blur 8 opacity 0.06。
- 禁止：重阴影。

## 组件规范
- 按钮：圆角 + 纯色或描边。
- 卡片：圆角 + 白底 + 微阴影。
- 输入框：圆角 + 细线。
- 导航：极简 + 左对齐。
- 弹窗：圆角 + 白底。

## 动效
- 极简过渡，微妙位移。150–300ms。
- 控制特效使用程度。
- 禁止：夸张动效、粒子。

## 特效
- 无。最多淡入淡出。

## 实现要点（所有风格里实现成本最低）

### SwiftUI
- 系统原生控件直接可用：`List` / `Form` / `Button`。
- 主色唯一：`Asset Catalog` 里定义一个 AccentColor，全局引用，禁止散落硬编码。
- 卡片：`RoundedRectangle(cornerRadius: 12).fill(.white).shadow(color: .black.opacity(0.06), radius: 8, y: 2)`。
- 动效：`.animation(.easeOut(duration: 0.2), value: ...)`，opacity + 微位移。

### Compose 映射
| 概念 | 等价物 | 注意 |
|---|---|---|
| 主色唯一 | MaterialTheme(colorScheme = lightColorScheme(primary = ...)) 单点定义 | — |
| 卡片 | Card / Surface(shape = RoundedCornerShape(12.dp), tonalElevation = 0) + 自绘微阴影 | tonalElevation 会带色偏，直角白底风格关闭它 |
| 动效 | tween(200, FastOutSlowInEasing) fade | — |
| 12 列网格 | 自定义 Layout 或 Column 简化 | 大多场景单列足够 |

### Web / CSS
- 纯 CSS 无框架即可：卡片 `box-shadow: 0 2px 8px rgba(0,0,0,0.06); border-radius: 12px;`
- 字体：Inter / 思源黑体（Google Fonts 免费）。
- 留白用 `--space` CSS 变量统一 8pt 梯度。

## 可访问性
- 黑白灰体系对比天然达标：#333 on #FFF ≈ 12:1。
- 主色按钮文字对比：蓝 #0055FF 配白字 ≈ 4.6:1 达标；绿 #00A86B 配白字 ≈ 3.0:1 只可用于大字号按钮，正文级小字禁止；红 #E30613 配白字 ≈ 5:1 可用。
- 焦点唯一对认知无障碍是加分项：每屏一个任务，Tab 顺序即阅读顺序。
- Reduce Motion：淡入淡出即可。

## 禁用
装饰元素、多色强调、复杂纹理、夸张动效、拥挤布局。

## 自检清单
- [ ] 每屏是否只有一个视觉焦点？
- [ ] 主色是否唯一且占比 ≤30%？
- [ ] 是否零装饰（出现纹理/玻璃/多色 = 残留）？
- [ ] 留白是否充足？
- [ ] 层级是否靠留白与大小对比建立（而非阴影堆叠）？

## 适用
生产力工具、编辑器、高端官网、数据面板、效率 App。
