# S8 · 高级庄重中国风

关键词：文化克制、朱红/金/墨/月白、天青/月白/缃色/墨灰、对称、水墨、仪式感。
公理：沉静中见绚烂；色名即文化；克制即高级；留白即意境。
决策顺序：文化基调（宫廷/宋式二选一，不混） → 对称布局 → 留白意境 → 材质纹理（水墨/宣纸/金丝） → 动效（晕染/展开）。

## 色彩系统
### 庄重宫廷路线
- 朱红 #C3272B 主色。
- 金 #C9A961 强调。
- 墨 #1C1C1C 深度。
- 月白 #F5F0E6 留白。
- 紫砂 #6B4A3A 辅助。
### 宋式文人路线
- 天青 #7BA8A0 主色。
- 月白 #F0EDE5 留白。
- 缃色 #D4B483 强调。
- 墨灰 #3A3A3A 深度。
- 黛蓝 #4A5C6A 辅助。
- 比例：主 40%、留白 40%、强调 15%、深度 5%。
- 禁止：高饱和红金大面积滥用。

## 字体系统
- 标题：宋体（思源宋体 / 方正宋刻本秀楷）或书法体（克制使用）。
- 正文：干净无衬线（思源黑体）或宋体。
- 字号：标题 32/40/48pt，正文 16/18pt。
- 字间距：标题 2–4，正文 0.5–1。
- 可竖排点缀。
- 禁止：大面积书法字体、难以阅读的字体。

## 形状与布局
- 对称布局，九宫格。
- 圆角：0–8 或直角。
- 金丝边框、细线装饰。
- 间距：16/24/32/48/64。
- 留白充足，意境感。

## 材质
- 水墨质感、宣纸纹理、金丝描边、紫砂底。
- 弱毛玻璃可用于现代中式。
- 禁止：重玻璃、霓虹。

## 阴影
- 极淡或水墨晕染感。
- 禁止：重阴影、硬阴影。

## 组件规范
- 按钮：金丝描边或朱红填充 + 圆角小。
- 卡片：宣纸底 + 金丝边。
- 输入框：细线 + 月白底。
- 导航：对称 + 宋体标题。
- 弹窗：卷轴或圆角 + 金丝边。

## 动效
- 水墨晕开、卷轴展开、雨幕、渐显。缓慢庄重。400–800ms。
- 禁止：快速、生硬、夸张。

## 特效
- 水墨晕染、金箔、宣纸纹理、雨幕、云雾。

## 实现要点

### Web / CSS
- 字体：思源宋体 Noto Serif SC + 思源黑体 Noto Sans SC（Google Fonts 免费商用）；标题 `letter-spacing: 2–4px`。
- 金丝边：`border: 1px solid #C9A961` + 伪元素外圈 1px 细线（间距 4px 双描边）。
- 宣纸纹理：SVG feTurbulence 或低透明噪点 PNG，`opacity ≤ 0.06`。
- 动效：卷轴展开 `clip-path: inset(0 50%) → inset(0)` 600ms ease；水墨晕开 radial-gradient mask 扩散 800ms。
- 金箔：linear-gradient(90deg, #C9A961, #E0D5A8, #C9A961) 细线或文字背景 clip。

### SwiftUI
- 金丝描边：`.overlay(RoundedRectangle(cornerRadius: 4).stroke(LinearGradient(colors: [#C9A961, #E0D5A8, #C9A961], ...), lineWidth: 1))`。
- 纹理：宣纸图 asset 叠加 `.opacity(0.06)`，`.allowsHitTesting(false)`。
- 动效：`.animation(.easeInOut(duration: 0.6))`；晕染用 mask + radialGradient 渐变。

### Compose 映射
| 概念 | 等价物 | 注意 |
|---|---|---|
| 宋体标题 | 打包 Noto Serif SC 字体文件（OFL 许可可商用） | 别依赖系统字体 |
| 金丝描边 | Modifier.border(1.dp, Brush.linearGradient(金三停), shape) | — |
| 宣纸纹理 | 纹理图 asset 叠 Image alpha 0.06 | — |
| 对称布局 | Row/Column + Arrangement.Center + 固定对称 padding | — |
| 竖排点缀 | 无原生竖排：手写逐字 Column 或仅用于 logo/题字 | 诚实告知成本，正文禁竖排 |
| 动效 | tween(600–800, FastOutSlowInEasing)，AnimatedVisibility | — |

## 可访问性
- 墨 #1C1C1C on 月白 #F5F0E6 ≈ 14:1 达标；宋体正文 16pt 起步（衬线小字易糊）。
- **金 #C9A961 on 月白 ≈ 2.4:1 —— 金色只用于装饰线/边框，禁止作正文与标题文字色**。
- 书法体只用于 logo/题字（配合替代文本），正文必须宋体/黑体。
- 动效缓慢但必须可跳过：Reduce Motion → 直接渐显或瞬间呈现；卷轴/晕染不得阻塞内容可达。
- 装饰性水墨/纹理标记 `aria-hidden` / 语义层排除。

## 禁用
高饱和红金大面积滥用、廉价龙凤图案、符号堆砌、花哨动效。

- [ ] 金色是否只作装饰、未作文字色？
- [ ] 是否避免了廉价龙凤与符号堆砌？

## 适用
文化品牌、茶/酒/香道、高端礼品、文博展览、中式生活方式。
